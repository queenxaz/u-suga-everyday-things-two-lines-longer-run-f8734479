A toaster, explained to a 10-year-old through a sunbathing analogy — and
then an honest second line about what the analogy maps and what it leaves
out.

## The entry

**A toaster is a tiny sunbathing bed for bread: it lies under hot wires until it turns golden, then pops up when it is done.
The analogy works because both use heat and timing, but it leaves out that bread cannot choose when to get up — the spring decides.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
